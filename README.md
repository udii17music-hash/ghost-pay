# GhostPay — Python Flask Demo

A responsive payment-code wallet demo inspired by the supplied UI references.

## Features
- Login/logout
- Demo wallet balance
- Create one-time payment codes + 4-digit PIN
- Expiry validation
- Redeem payment code
- Transaction history
- Admin-style dashboard
- SQLite database
- Responsive mobile-friendly UI

## Run
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

This is a local/demo wallet, not a real payment service. Do not use it to store real money, financial credentials, or production payment data.
